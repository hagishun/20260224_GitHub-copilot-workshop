# ポモドーロタイマー 実装機能一覧

## バックエンド（Python / Flask）

| # | 機能 | ファイル | 説明 | ステータス |
|---|------|---------|------|-----------|
| 1 | アプリファクトリ | `app.py` | `create_app(config)` パターンでFlaskアプリを生成、ルーティング登録 | [ ] |
| 2 | 設定管理 | `config.py` | `Config`（本番用）/ `TestConfig`（テスト用）の定義。作業時間・休憩時間等の定数管理 | [ ] |
| 3 | セッションモデル | `models/session.py` | `@dataclass` で `Session`（id, duration_minutes, completed_at）を定義 | [ ] |
| 4 | リポジトリ層 | `repositories/session_repository.py` | インメモリでのデータ永続化（`save`, `find_by_date`, `clear`） | [ ] |
| 5 | サービス層 | `services/pomodoro_service.py` | ビジネスロジック（`complete_session`, `get_today_stats`）、DIでリポジトリを注入 | [ ] |
| 6 | APIルート: GET / | `app.py` | `index.html` テンプレートを返す | [ ] |
| 7 | APIルート: POST /api/sessions | `app.py` | セッション完了を記録し、id と completed_at を返す（201） | [ ] |
| 8 | APIルート: GET /api/sessions/today | `app.py` | 今日の完了セッション数・累計集中時間を返す（200） | [ ] |
