# ポモドーロタイマー 実装プラン

## 全体の流れ

```
Phase 1  プロジェクト基盤
   ↓
Phase 2  Flask + 静的ページ表示    ← ここで画面が見える
   ↓
Phase 3  タイマーロジック（TDD）   ← テスト駆動で品質確保
   ↓
Phase 4  UI連携                   ← タイマーが動く
   ↓
Phase 5  バックエンド API（TDD）   ← データ永続化
   ↓
Phase 6  API連携                  ← コア機能完成 ✅
   ↓
Phase 7  UX向上                   ← 使いやすく
   ↓
Phase 8  可視化                   ← モチベーション向上
   ↓
Phase 9  カスタマイズ・信頼性      ← 仕上げ
```

**Phase 6 までで MVP（最小限の動作するプロダクト）が完成。Phase 7〜9 は優先度に応じて取捨選択可能。**
